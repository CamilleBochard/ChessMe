# Openings table

`a.tsv` to `e.tsv` are Lichess's table of chess openings, copied unmodified
from [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings)
at commit `a6189a30dc273ccb21fc2536a9a2fefd5592a67a`. Each line gives an ECO
code, the opening's name and its moves.

`pipeline/build_player_record.py` names the openings of Camille's games with
it, for the record the game page shows.

The table is in the public domain, released by its authors under the
[CC0 1.0 Public Domain Dedication](https://creativecommons.org/publicdomain/zero/1.0/).
